# Аналитическая система для сети магазинов "Пикча"

## Описание проекта
Создание ETL пайплайна для аналитики покупательского поведения.

## Структура проекта
- `data_generation/` - генераторы тестовых данных
- `etl/` - ETL процессы
- `analytics/` - аналитические витрины
- `config/` - конфигурации

## Технологии
- Python, PySpark, ClickHouse
- SQL, JSON, Data Analysis
