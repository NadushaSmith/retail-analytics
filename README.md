# Аналитическая система для сети магазинов "Пикча"

## Описание проекта
Создание ETL пайплайна для аналитики покупательского поведения и оптимизации продаж.

## Структура проекта

### 📁 data_generation/ - Генераторы тестовых данных
- **products.py** - Генератор товаров (100+ товаров, 5 категорий)
  - Молочные продукты, Овощи и зелень, Фрукты и ягоды, Мясо/рыба, Зерновые
  - Полные атрибуты: КБЖУ, производители, цены, сроки годности
  - Реалистичные вариации и характеристики

- **customers.py** - Генератор покупателей (50+ профилей)
  - Демографические данные, контакты, предпочтения
  - Программа лояльности, истории покупок
  - Адреса доставки и магазины привязки

- **purchases.py** - Генератор покупок (200+ транзакций)
  - Реалистичные корзины по 1-5 товаров
  - Связь с существующими покупателями и товарами
  - Данные о доставке, оплате, времени покупок

### 📁 etl/ - ETL процессы
*(в разработке)* - процессы загрузки и преобразования данных

### 📁 analytics/ - Аналитические скрипты  
*(в разработке)* - витрины данных и аналитика

### 📁 config/ - Конфигурации
*(в разработке)* - настройки подключений к БД

### 📁 docs/ - Документация
- architecture.md - описание архитектуры системы

## 🚀 Быстрый старт

```bash
# Сгенерировать все тестовые данные
python data_generation/products.py
python data_generation/customers.py  
python data_generation/purchases.py

# Данные появятся в папке data/ (не включено в репозиторий)
